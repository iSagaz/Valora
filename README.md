# Valora

### Comparador de produtos e preços

O Valora é um projeto web desenvolvido para demonstrar uma interface de comparação de produtos e preços, permitindo pesquisar itens e visualizar seus valores de forma organizada.

## 🚀 Funcionalidades

- **Busca de produtos:** consulta de produtos utilizando a Fetch API.
- **Exibição de resultados:** apresentação de imagens, títulos, marcas e preços.
- **Formatação de valores:** preços exibidos no formato monetário brasileiro (BRL).
- **Gráfico comparativo:** visualização dos preços encontrados por meio de um gráfico de barras.
- **Interface responsiva:** layout adaptável a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- DummyJSON
- Chart.js

## 📷 Sobre os dados

O projeto utiliza a API [DummyJSON](https://dummyjson.com/) para obter dados de produtos.

**Importante:** os preços apresentados são dados fictícios fornecidos pela API. As marcas exibidas não representam lojas ou vendedores reais, e o gráfico apresenta uma comparação dos valores retornados na busca, não um histórico de preços.

## 🎯 Objetivo

O Valora foi desenvolvido como projeto de aprendizagem, com o objetivo de praticar consumo de APIs, manipulação do DOM, organização de dados com JavaScript e visualização de informações utilizando gráficos.
